# Portfolio — Felipe Rodrigues de Sousa

Site pessoal estático em HTML, CSS e JavaScript, com versões em português e inglês.

## Estrutura

- index.html: estrutura da página e conteúdo semântico.
- css/style.css: estilos, layout responsivo e detalhes visuais.
- js/app.js: menu mobile e troca de idioma.
- content/pt.json e content/en.json: textos nos dois idiomas.
- images/: imagens do portfólio.

## Publicar no GitHub Pages

1. Crie o repositório público site-portfolio na conta fr353085-ai.
2. Envie o conteúdo desta pasta para a raiz do repositório.
3. No GitHub, abra Settings → Pages.
4. Em Build and deployment, escolha Deploy from a branch, branch main e pasta / (root).
5. A URL esperada será https://fr353085-ai.github.io/site-portfolio/.

Os arquivos JSON de idioma são carregados pelo navegador; abra o site por um servidor local ou pelo GitHub Pages. Abrir index.html diretamente como arquivo não carrega esses idiomas.
